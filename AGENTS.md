# Правила для агентов (Codex, Claude и др.)

«Между уроками» — тренажёр для учеников репетитора. Статический PWA на
ванильных ES-модулях: без сборки, без npm, без фреймворков. API — Cloudflare
Worker в `worker/`, он же раздаёт статику (`wrangler.jsonc` в корне).

## Карта файлов

| Файл | Что это |
|---|---|
| `index.html`, `app.js` | приложение ученика (роуты `#/library`, `#/topic`, `#/me`, сессия) |
| `landing.js` | главная для репетиторов (`/` без набора или `/?about`) |
| `studio/` | кабинет репетитора: наборы, карточки, ученики, публикация |
| `lib.js` | общее: хранилище, API, рендер карточек (`renderCard`) |
| `app.css` | **все** стили: приложение, студия, лендинг (`.landing`, классы `ld-*`) |
| `img/`, `icons/`, `manifest.webmanifest` | картинки, иконки, манифест PWA |
| `sw.js` | service worker, офлайн-кэш |
| `packs/*.json` | готовые наборы — **генерируются**, руками не править |
| `data/`, `tools/` | исходные данные и генераторы наборов (`python3 tools/build_packs.py`) |
| `worker/worker.js` | API: ИИ (Gemini), публикация наборов, прогресс учеников |

## Кто за что отвечает

- **Codex — дизайн:** `app.css`, HTML-разметка в шаблонных строках
  (`landing.js`, `app.js`, `studio/studio.js`), `img/`, `icons/`, манифест.
- **Claude — логика и данные:** JS-логика, `worker/`, `tools/`, `data/`, `packs/`,
  конфиги деплоя.
- Если для дизайна нужно поменять логику — отдельный маленький PR с объяснением.

## Дизайн-система

- Цвета — только через токены из `:root` в `app.css`: `--accent`, `--bg`,
  `--surface`, `--line`, `--text`, `--muted`, `--ok`/`--ok-bg`, `--bad`/`--bad-bg`,
  `--mid`/`--mid-bg`, `--radius`, `--shadow`. Лендинг: `--ld-ink`, `--ld-cream`,
  `--ld-sun`, `--ld-card`, `--ld-soft` (на `.landing`).
- Есть тёмная тема (`@media (prefers-color-scheme: dark)`). Новый токен или цвет
  — сразу задать и для неё.
- Системный шрифт. Без внешних шрифтов и CDN: приложение работает офлайн.
- Мобильные в приоритете: от 360px, без горизонтального скролла, кнопки ≥ 44px.
- `<textarea>`/`<input>` не класть внутрь `<label>` — на iOS в них не печатается.
- Не переименовывать классы и `id`, на которые опирается JS: перед изменением
  искать их grep'ом по `*.js`.

## Нельзя

- Добавлять фреймворки, сборку, `package.json`, внешние скрипты и шрифты.
- Править `packs/*.json` руками.
- Коммитить ключи и токены (ключ Gemini живёт только в секретах Cloudflare).
- Менять `config.js`, `wrangler.jsonc`, `.assetsignore` без согласования.

## Обязательно

- Изменили любой статический файл (css/js/html/картинки) — поднять версию
  `CACHE = 'zadachnik-vN'` в `sw.js`, иначе пользователи увидят старую версию.
- Новые служебные файлы, которые не нужны на сайте, — добавить в `.assetsignore`.

## Git

- Свои ветки: Codex — `codex/<тема>`, Claude — `claude/<тема>`. Один PR — одна тема.
- Перед PR подтянуть свежий `main`, чтобы не конфликтовать с чужими ветками.
- Сообщения коммитов — по-русски, коротко, как в истории.

## Как проверить

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080/`, `/?about`, `/#/library`, `/?p=ege-rus`,
`/studio/`. Проверить ширину 375px и 1280px, светлую и тёмную тему, пройти
несколько карточек до экрана «Готово». ИИ-функции локально без воркера не
работают — это нормально.
