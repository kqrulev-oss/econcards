# EconCards

Тренажёр-приложение для подготовки к олимпиадам по экономике и к ЕГЭ.
Работает офлайн (PWA), весь прогресс хранится на устройстве. Листаешь
карточки как ленту — в метро, в очереди, за пять минут.

**Живая версия:** GitHub Pages (ветка со статикой) — открой `index.html`.

## Что внутри

Приложение делится на разделы (экран «Разделы»):

### 🏆 Олимпиады
- **Экономика** — 1366 задач с разборами (ВсОШ, МОШ, Высшая проба, Сибириада,
  РАНХиГС, СПбГУ, РЭШ, IEO) по темам: спрос и предложение, эластичность,
  издержки и прибыль, типы рынков, поведение потребителя, торговля и КПВ,
  ВВП, госбюджет и налоги, деньги и банки, инфляция, неравенство, теория игр,
  вероятность и статистика.
- Курсы: Микроэкономика, Макроэкономика, Финансы и рынки, Математика для
  экономиста, Практикум — короткая теория, а сразу за ней карточки по теме.
  Теория собрана из книг (Бойко, Марков, Хейне) и конспектов кружка.

### 🎓 ЕГЭ
- **Русский язык** — курс из 27 уроков (по одному почти на каждое задание +
  сочинение) с полной теорией и тренажёр из ~1250 карточек по типам заданий.
  Орфография и пунктуация — по справочнику Розенталя.
- Профильная математика, английский, информатика — в планах.

## Возможности
- **Интервальное повторение (SRS)** — карточки возвращаются тогда, когда
  начинаешь забывать.
- **Режим пробника** — таймер и набор заданий, разбор ошибок.
- **Интерактивные модели** — спрос/предложение, налог и мёртвый груз,
  издержки, полезность: точку можно тащить прямо по графику.
- **AI-репетитор** (опционально) — проверка решения, подсказки, объяснение
  проще, «другие числа». Бесплатно через прокси на Cloudflare Worker
  (см. `ai/`).
- **Фильтры** — по теме/заданию, «работа над ошибками», «на повторение»,
  избранное, класс, «только обратные задания».
- **Напоминания**, streak, XP и уровни сложности карточек.

## Как устроено
- `index.html` — всё приложение одним файлом: разметка, стили, данные
  (карточки и курсы в `<script type="application/json">`) и логика.
- `sw.js` — service worker: полный офлайн после первого открытия.
- `manifest.webmanifest`, `icons/` — установка как PWA.
- `img/` — иллюстрации к заданиям.
- `ai/` — Cloudflare Worker для бесплатного AI-репетитора и инструкция по
  развёртыванию.

## Разработка
Статический сайт — достаточно открыть `index.html` в браузере или отдать
любым статик-сервером (`python3 -m http.server`). При обновлении данных
нужно поднять версию кэша в `sw.js`, чтобы клиенты подтянули новую сборку.
