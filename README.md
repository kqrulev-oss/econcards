# Между уроками — тренажёр репетитора

Репетитор за 15 минут собирает тренажёр из своих материалов и отправляет ученикам ссылку. Ученики занимаются по 10 минут в день: карточки возвращаются по интервальному повторению, открытые задачи проверяет ИИ. Репетитор видит, кто занимался и где ошибается, и в один клик получает отчёт для родителей.

## Как устроено

| Часть | Где | Что делает |
|---|---|---|
| Приложение ученика | `index.html`, `app.js` | ежедневное занятие, темы с теорией, работа над ошибками, отправка прогресса |
| Студия репетитора | `studio/` | карточки из материалов (ИИ) и из библиотеки, редактор, публикация, прогресс учеников |
| Общий код | `lib.js`, `app.css` | загрузка наборов, запросы к серверу, отрисовка и проверка карточек |
| Сервер | `worker/` | Cloudflare Worker: ИИ, хранение наборов, прогресс. Разворачивается кнопкой ниже, подробности — `worker/README.md` |
| Библиотека | `packs/` | готовые наборы, собираются из `data/source/` скриптом `tools/build_packs.py` |
| Данные | `data/source/`, `img/` | всё содержимое прежних приложений (EconCards, Сотка, Ударение, Сочинение) без потерь |

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/kqrulev-oss/econcards/tree/main/worker) — сервер в один клик: нужен только ключ Gemini.

Сайт статический: работает на GitHub Pages и офлайн (PWA). Без сервера доступна библиотека. ИИ, публикация тренажёров и отчёты работают, когда в `config.js` указан адрес Worker'а.

### Ссылки
- `./` — выбор набора или код от репетитора
- `./?p=ege-rus` — открытый набор из библиотеки
- `./?t=<код>` — тренажёр репетитора, опубликованный через студию
- `./studio/` — студия

## Открытый банк ФИПИ
Задания [открытого банка ФИПИ](https://ege.fipi.ru/bank/) по всем предметам ЕГЭ (и ОГЭ) превращаются в наборы по образцу `ege-rus` и `ege-math`: темы — разделы кодификатора, внутри — его пункты (как прототипы), карточки — задания с ключом. Русский и профильная математика дополняют готовые наборы разделом «Открытый банк ФИПИ» под сеткой заданий, остальные предметы получают свои наборы: `ege-phys`, `ege-chem`, `ege-inf`, `ege-bio`, `ege-hist`, `ege-soc`, `ege-geo`, `ege-lit`, `ege-math-base`, `ege-eng`, `ege-de`, `ege-fr`, `ege-es`, `ege-zh` (ОГЭ — `oge-…`).

Ответов в банке нет, зато сайт ФИПИ проверяет ответ. Поэтому в набор попадает только то, что ФИПИ подтвердил: выбор ответа — перебором вариантов, краткий ответ — кандидат от Gemini (или из своего файла), который ФИПИ признал верным; решение Gemini к подтверждённому ответу становится разбором. К развёрнутым заданиям Gemini пишет решение-образец, в карточке оно помечено как решение ИИ. Аудирование (задания со звуком) пропускается.

Сайт банка открывается из России (с зарубежных адресов часто недоступен), запускать там:
```
python3 tools/fipi_bank.py                       # 1. скачать банк ЕГЭ → data/source/fipi/, картинки → img/fipi/
GEMINI_KEY=… python3 tools/fipi_answers.py --ai  # 2. ответы с проверкой на сайте ФИПИ (--solutions — решения к развёрнутым)
python3 tools/build_packs.py                     # 3. собрать наборы
```
Отдельные предметы: `python3 tools/fipi_bank.py physics chemistry` (ключи — `--list`), ОГЭ — `--exam oge`. Оба скрипта продолжают с места остановки: страницы банка кэшируются в `data/fipi-cache/` (не в git), найденные ответы — в `data/source/fipi/<экзамен>-<предмет>-answers.json`. `--offline` пересобирает JSON из кэша без сети — если поменялся разбор страниц. Если Python не доверяет сертификату ФИПИ, укажите корневой сертификат Минцифры в `FIPI_CA=…`.

Условия заданий хранятся с разметкой (поле `h`): таблицы, картинки и формулы MathML, которые браузер рисует сам. Приложение пропускает в разметке только безопасные теги — поле может прийти и в наборе репетитора.

## Каталог заданий ЕГЭ
В наборе «ЕГЭ: русский язык» темы — это задания 1–27 (номер `n`, баллы `pts`), а внутри заданий — прототипы (`protos`), к которым привязаны карточки (поле `p`). Ученик видит сетку номеров с прогрессом, экран задания с прототипами и подсказкой «как решать» и пробный вариант: по карточке на каждое задание части 1 с первичным баллом.

Прототипы размечены ИИ один раз и лежат в `data/source/ege-rus-prototypes.json`:
```
GEMINI_KEY=… python3 tools/classify_prototypes.py [номера заданий]
python3 tools/build_packs.py
```
В банке Сотки задания 1–3 пронумерованы по старой схеме — `exam_task()` в `build_packs.py` раскладывает их по действующей спецификации.

## Типы карточек
`one` (один ответ), `many` (несколько), `match` (соответствие), `flip` (вопрос → ответ), `open` (развёрнутое решение: ученик сверяется с эталоном или ИИ), `stress` (ударение), `num` (число, как в бланке ЕГЭ), `short` (краткий ответ словом или цифрами; `any` — порядок цифр не важен). Формат описан в начале `tools/build_packs.py`.

## Разработка
```
python3 -m http.server 8080          # открыть http://localhost:8080
python3 tools/build_packs.py         # пересобрать packs/ после правки data/source/
```
Если поменялся состав файлов приложения, поднимите версию кэша в `sw.js`.
