# Проверка сайта «как живой человек»

Скрипты проходят сайт в браузере. Папка `tools` не выкладывается на сайт (`.assetsignore`).

Проверка смотрит:
- все ссылки и кнопки;
- переходы и «назад»;
- офлайн;
- скорость на медленной сети.

По умолчанию проверяется живой сайт. Можно проверить и локальный.

## Только чтение

Живой сайт проверяется **без входа в аккаунт и без записей на сервер**.

- `lib.cjs` не пропускает к сайту никакие запросы, кроме GET.
- Он же не пускает к пишущим путям: вход, отправка прогресса, оплата, ИИ, бот.
- Такие попытки перечислены в отчёте (раздел 6). Ожидаемы кнопки входа.
- Внешние адреса не открываются. Telegram подменяется заглушкой.

## Запуск

```bash
bash tools/audit/run-live.sh                         # живой сайт, всё (~1 ч)
QUICK=1 bash tools/audit/run-live.sh                 # без обхода всех кнопок (~15 мин)
OUT=/tmp/check bash tools/audit/run-live.sh https://econcards.kqrulev.workers.dev
```

Итог — `$OUT/report.md`, по умолчанию `tools/audit/out/<дата-время>/report.md`. Рядом лежат:
- JSON с подробностями — `results/`;
- скриншоты — `shots/`.

Нужны Node ≥ 22 и Playwright с Chromium. В облачной среде Claude Code запуск такой:
`NODE_PATH=$(npm root -g)`, браузер в `/opt/pw-browsers`. Если за прокси, встроенный `fetch` в Node требует `NODE_USE_ENV_PROXY=1` — `run-live.sh` ставит его сам.

## Части

| Файл | Что делает |
|---|---|
| `http.mjs` | Проверяет адреса без браузера: статусы, перенаправления, кэш, сжатие, размер. Показывает способы входа на сервере и бесплатную часть библиотеки. |
| `journeys.cjs` | Три пути со скриншотами шагов. Новый репетитор: «Попробовать» → пример → глазами ученика → «Ученики» → «Опубликовать» (до входа). Ученик библиотеки. Навигация. |
| `offline.cjs` | Офлайн с service worker. Сеть выключается прокси-выключателем, потому что `setOffline` не действует на service worker. |
| `perf.cjs` | Скорость переходов: обычная сеть, «3G», повторно, повторно с service worker. |
| `throttle-proxy.mjs` | Прокси для «3G»: задержка 562 мс, 1,44 Мбит/с. Замедляет и service worker. |
| `crawl.cjs` | Нажимает каждую ссылку и кнопку для ролей `guest`, `guest-draft`, `library`. После каждого нажатия проверяет: ошибки, висящие окна, пустой экран, «назад», перезагрузку. |
| `report.cjs` | Собирает сводку `report.md`. |

## Локально

Статика и сервер должны отвечать на одном адресе, как в Cloudflare. Для этого есть мок-воркер и прокси из рабочих заметок. `API` подставляется сам: для localhost это `BASE`.

```bash
BASE=http://localhost:8090 NODE_PATH=$(npm root -g) node tools/audit/journeys.cjs 375
```
