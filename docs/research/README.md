# Исследования: массовое создание заданий по предметам

Собрано 26–28.09.2026 из 11 рабочих веток (7 исследований и 4 сессии прототипов). Здесь — общая картина и план. Подробности по предметам — в файлах рядом.

Метод везде один, «как у Решу ЕГЭ»: на каждый вид задания экзамена заводится **прототип** (что неизменно, что меняется, как проверяется ответ), а **генератор** делает по нему много похожих, но не одинаковых заданий. Тексты ФИПИ, Решу ЕГЭ и других банков в репозиторий не копируются — только структура экзаменов, коды кодификатора и факты. Главный критерий приёмки — **экзаменационность**: аналог должен быть неотличим от задания КИМ по форме, уровню и способу ответа.

## Объём

Оценка уникальных карточек, которые можно собрать из готовых генераторов без расширения шаблонов (ёмкость по самопроверке):

| Предмет | Ёмкость сейчас | Что ограничивает |
|---|---|---|
| Математика | ≈ 1,09 млн (минимум 52 на прототип, медиана 1315; `llm`-рецепты — ещё ≈ 10 тыс.) | одинаковые сюжеты в шаблоне; рисунки только у 217 прототипов |
| Физика и химия | ≥ 134 тыс. (предел 300 на прототип, у 548 из 560 упёрлось в предел) | рисунки; база фактов по химии требует вычитки |
| Биология и география | ≈ 910 тыс. | рисунки и карты |
| Русский | словарные — сотни на прототип; `llm` — по цене проверки | ОГЭ 9: 10–25 вариантов |
| Информатика | ≈ 150 тыс. | файловые задания только в мини-версии |
| Английский | ≈ 29 тыс. (времена — 2000+ на прототип, рамочные и словарные — 15–350) | одиночные предложения вместо связного текста; рамочные прототипы — по числу рамок |

Ученику при 10 минутах в день хватает 150–300 карточек на вид задания. Запас нужен для разнообразия и для разных учеников, а не для показателя «сколько всего».

## Что нужно в приложении

Сейчас `lib.js` проверяет `num` точно, `one`/`many` по набору вариантов, `flip`/`open` — самооценкой. Для экзаменационной формы ответа не хватает:

1. **`word`** — ответ словом, как в бланке КИМ: без регистра и пробелов, ё = е, несколько допустимых через `|`. Нужен русскому (все словарные прототипы), биологии и географии (термины, названия), истории.
2. **`seq`** — последовательность цифр, где важен порядок, с **частичным баллом** как в ЕГЭ (2 балла за полное совпадение, 1 балл за одну ошибку). Нужен физике, химии, биологии, географии, истории. Пока такие ответы хранятся как `num`, но подсказка поля ввода не подходит.
3. **`tol`** — допуск для числового ответа (задание 19 ЕГЭ по физике, «округлил иначе»).
4. **Рисунки**: SVG по тем же параметрам, что и условие (графики, клетчатая бумага, схемы цепей, карты). Без них не закрыть 41 прототип био/гео, задания по графику в математике и физике.

Всё это — изменения в `lib.js`, `app.js` и сборке наборов. Отдельная работа, не часть исследования.

## Порядок первых тренажёров

Рекомендация, исходя из готовности генераторов и спроса у репетиторов:

1. **Математика, ЕГЭ профиль 2027** — генераторы готовы по всем 20 заданиям в новой нумерации, ответы проверены пересчётом; это самый частый предмет у репетиторов. Часть 1 сразу, к части 2 — шаговые карточки.
2. **Русский, ОГЭ** — словарные прототипы прошли экспертизу, нужен тип `word`.
3. **Физика и химия, расчётные задания** — `param`-прототипы готовы; сначала ЕГЭ физика 1–20 и ЕГЭ химия 21–28, где проверка числом.
4. **Биология** — после `seq` и `word`; движки и таблицы готовы.
5. Английский — грамматика и словообразование готовы (каталог и генератор), нужен тип `word`; информатика (генераторы есть, каталога прототипов нет), география, обществознание и история — по мере появления каталогов и типов ответа.

## Как запускать

```
pip install sympy pymorphy3 pymorphy3-dicts-ru
python3 tools/research/gen_math.py --protos --n 50 [--exam oge]
python3 tools/research/gen_phys_chem.py --protos --n 50 --cap 300
python3 tools/research/gen_bio_geo.py --protos
python3 tools/research/gen_rus.py --check -n 50
python3 tools/research/gen_inf.py
python3 tools/research/gen_eng.py
python3 tools/research/gen_eng.py --protos [--export --tables]
```

Полная самопроверка математики (787 прототипов, ёмкость до 4000 попыток) идёт больше 25 минут; для быстрого прогона задавайте `--exam` или `--proto`. `protos_report.py` не запускать: он переписывает отчёты старыми цифрами.
