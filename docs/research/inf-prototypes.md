# Информатика: каталог прототипов и генераторы аналогов

Продолжение [inf-eng.md](inf-eng.md). Там — структура экзаменов и 36 первых генераторов. Здесь — каталог прототипов «как у Решу ЕГЭ»: на каждый вид задания ЕГЭ (нумерация проекта КИМ 2027) и ОГЭ свой прототип, по нему генератор делает много похожих, но не одинаковых заданий.

Код: `tools/research/gen_inf.py --protos` и модуль `proto_inf.py` (реестр прототипов, новые генераторы, привязка 36 старых, самопроверка, экспорт). Каталог в машинном виде: `data/source/inf-prototypes.json` (`gen_inf.py --protos --export`). Вердикты экзаменационной проверки: `data/research/inf-fidelity.json` (`--fidelity` переписывает их в каталог). Код сайта не менялся.

- **Новые генераторы** (сверх 36 из inf-eng.md): ЕГЭ 2 в форме КИМ (фрагмент таблицы истинности → порядок переменных, ответ буквами; старый генератор считал строки, что не соответствует КИМ), ЕГЭ 7 объём изображения числом (вместо выбора из вариантов), ЕГЭ 13 (2 вида), ЕГЭ 15 ДЕЛ (наименьшее и наибольшее A), ЕГЭ 23 (2 вида), ОГЭ 12 (файлы по маске), ОГЭ 14 (мини-таблица: количество и среднее), ОГЭ 16 (программа для последовательности и трассировка цикла). Три прототипа ОГЭ без генератора — рецепты `llm`: 11 (поиск в файлах), 13 (презентация/документ), 15 (Робот).
- **Файловые задания** (ЕГЭ 3, 9, 17, 18, 22, 24, 26, 27; ОГЭ 12, 14) — мини-версии с данными в условии, как решено в inf-eng.md; поле `gen.mini` каталога говорит, что именно уменьшено. ЕГЭ 25 (маска/делители) помечен `pc`: честно решается программой.
- **Самопроверка** (28.09.2026, по 50 разных карточек на прототип, ёмкость до 300 попыток): 3 573 карточки по 72 прототипам с генератором, **0 несошедшихся ответов**, 0 повторов условий, 0 дублей между прототипами. У двух прототипов шаблон уже: ЕГЭ 8 «гласные не рядом» — 33 разных условия, ЕГЭ 15 ДЕЛ — 40 (все выданы и проверены). Ёмкость у 44 прототипов из 72 упёрлась в предел 300 (в каталоге «300+»), нижняя оценка суммарной ёмкости — около 19 тыс. разных карточек; реальная выше (в inf-eng.md при 5 000 попыток на тип оценка была ≈ 150 тыс.).
- **Что проверяется у каждой карточки:** ответ пересчитан вторым способом (другая формула, перебор, DFS вместо динамики, Флойд вместо Дейкстры, регулярные выражения вместо fnmatch); для программ (ЕГЭ 12, 16, 25; ЕГЭ 13 и ОГЭ 6, 16 — по листингу из условия) дополнительно выполняется эталонная программа на Python (`exec`) и её вывод сравнивается с ответом; условие не повторяет уже выданное; id карточек и тексты не совпадают между прототипами.
- **Экзаменационная проверка** (главный критерий): на каждый прототип взяты 3 случайных аналога (216 карточек, seed 7), проход в роли эксперта ЕГЭ по чек-листу — форма как в КИМ, уровень, однозначность ответа, запись ответа как в бланке, отличимо ли от банка ФИПИ. **Итог: 62 pass, 10 partial, 3 fail** (fail — три рецепта `llm` без генератора). Что partial, поправлено один раз (таблица ниже); второй раунд не делался.

## Как устроен прототип

Запись каталога: id вида `inf-ege-05-min-n` (предмет, экзамен, номер 2027, вид), заголовок, `invariant` (что неизменно), `varies` (что меняется), `answer_rule` (как считается ответ), `mistakes` (типичные ошибки), `passport` (уровень Б/П/В, балл, форма ответа, нужно ли ПО, тема кодификатора словами; числовые коды кодификатора не воспроизводятся), `gen` (функция генератора и фильтр подвида или рецепт), `capacity`, `selfcheck`, `fidelity`, `example` (наш, из генератора).

Привязка к старым генераторам — через фильтр по параметрам: например, `gen_ege13` из inf-eng.md даёт четыре подвида (`net_byte`, `mask_byte`, `count_addr`, `max_ones`), каждый стал отдельным прототипом ЕГЭ 10. Где у подвида не форма КИМ (ЕГЭ 7 с выбором из вариантов), написан новый генератор.

Пример (ЕГЭ 13, `inf-ege-13-digits-ab`): листинг из 11 строк на Python перебирает цифры x в восьмеричной записи, чётные складывает в a, нечётные перемножает в b; вопрос — наибольшее x, при котором печатаются 2 и 9. Ответ найден перебором x до 4095 по листингу и независимо разбором цифр без exec.

## Экзаменационная проверка: что было partial и что исправлено

| Прототип | Замечание эксперта | Исправление |
|---|---|---|
| ЕГЭ 2 фрагмент таблицы | подвыражение вида (x ∨ x) | выражения с одинаковыми операндами и ¬¬ отбрасываются |
| ЕГЭ 3 остаток за период | отрицательные ответы, в КИМ таких нет | отрицательные ответы отбрасываются |
| ЕГЭ 11 общий объём | длина пароля 119–213 символов | длина 6–40 символов |
| ЕГЭ 14 сколько цифр | ответ 0 в двух аналогах из трёх | нулевые ответы отбрасываются |
| ЕГЭ 16 рекуррентная функция | «1·F(n − 1)», «1·n» | единичный коэффициент не пишется |
| ЕГЭ 23 число путей | текст ссылался на рисунок, которого нет | «схема задана списком дорог» |
| ОГЭ 2 декодирование | сообщение из одной буквы | не меньше двух разных букв |
| ОГЭ 8 поисковые запросы | двойная точка после «тыс.» | точка убрана |
| ОГЭ 16 программа для последовательности | в КИМ ученик пишет программу, у нас — вывод верной программы на данных | оставлено как мини-форма (partial) |
| ОГЭ 16 трассировка цикла | форма «что напечатает» — тренировочная, в КИМ 16 такой нет | оставлено как упражнение (partial) |

Замечания без исправления (pass с пометкой): схема графа списком рёбер вместо рисунка (ЕГЭ 1, 23, ОГЭ 4, 9), падеж «32 секунд» (ЕГЭ 7 звук), низкое разнообразие ответов в ЕГЭ 24 «цепочка пар», один тривиальный аналог ЕГЭ 13 «цикл» с одной итерацией.
